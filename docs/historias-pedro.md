# Histórias de usuário

> Entregável da aula 20. Cada história nasce de uma oportunidade do mapa de jornada e vira uma Issue com o label `historia`.

| ID | História | Oportunidade de origem | Prioridade | Issue |
| --- | --- | --- | --- | --- |
| HU01 | Como cliente da Bulbe que vai mudar de endereço, quero saber o que acontece com meu contrato e pedir a transferência para o novo endereço, para continuar economizando sem cancelar. | #12 Explicar e facilitar a mudança de endereço sem cancelar o contrato | Alta | #[ ] |

## Critérios de aceite

### HU01
- [ ] O cliente deve conseguir entender, em linguagem simples, se mudar de endereço cancela o contrato ou transfere a titularidade.
- [ ] O cliente deve conseguir iniciar a transferência do contrato para o novo endereço pelo app ou WhatsApp.
- [ ] O cliente deve saber o que precisa informar e quanto tempo leva até a economia voltar.
- [ ] A tela deve deixar claro que consultar não inicia o cancelamento.

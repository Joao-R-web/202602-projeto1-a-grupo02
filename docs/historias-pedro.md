## Critérios de aceite

### HU01
- [ ] Exibir em uma tela o prazo de fidelidade, o valor da multa e a regra de reajuste, em linguagem simples.
- [ ] Mostrar quantos meses restam do contrato.

### HU02
- [ ] Calcular o valor da multa se o cliente sair hoje, indicando se incide sobre o total ou só sobre os meses restantes.
- [ ] Informar se existe carência ou janela sem multa.
- [ ] Deixar claro que a simulação não cancela o contrato.

### HU03
- [ ] Explicar a diferença entre cancelamento e transferência de titularidade na mesma concessionária.
- [ ] Mostrar os passos para transferir o contrato para um novo endereço.

### HU04
- [ ] Exibir aviso visível de que a consulta não inicia rescisão.
- [ ] Responder as dúvidas mais comuns (multa, reajuste, taxa de religação) sem exigir ligação.

### HU05
- [ ] Informar se a fatura dá direito a abatimento fiscal para MEI.
- [ ] Mostrar a economia estimada já considerando esse abatimento, quando aplicável.
